PrintSpoofer // Token Impersonation · Red

local service (SeImpersonate) → nt authority\system

The clean, fast way from a service account to SYSTEM — same token-impersonation idea as Rogue Potato, but it abuses the Print Spooler instead of the OXID resolver, so there's no socat and far fewer moving parts. Generic methodology from a public lab — nothing about the real PNPT exam (NDA).

i The idea

Same key as Rogue Potato: SeImpersonatePrivilege — the “badge” that lets a process wear the token of anything that authenticates to it. PrintSpoofer makes the Print Spooler service (running as SYSTEM) connect to a named pipe you control; when it does, you impersonate its SYSTEM token — and you're SYSTEM. Because the Spooler trick happens locally, there's no port-135 OXID resolver and no socat. That's why it's the easy one.

ii PrintSpoofer vs Rogue Potato

🥔 Rogue Potato

  • Key: SeImpersonate
  • Goal: wear SYSTEM's token
  • Coerces via the OXID resolver (port 135)
  • Needs socat (135 → 9999 redirect)
  • More moving parts

🖨️ PrintSpoofer

  • Key: SeImpersonate
  • Goal: wear SYSTEM's token
  • Coerces via the Print Spooler (named pipe)
  • No socat — it's all local
  • Often a one-liner
The cleanest trick: PrintSpoofer's interactive mode (-i -c cmd.exe) pops a SYSTEM shell right in your window — no reverse shell, no listeners, no ports to juggle. Run it from any context that holds SeImpersonate.

v The lesson (learned the hard way)

SeImpersonate only lives in a HIGH-integrity / service context. A plain admin prompt (C:\Users\admin>) is medium-integrity — UAC strips SeImpersonate out of it, and PrintSpoofer says "A privilege is missing: SeImpersonatePrivilege." Run it from a Run-as-administrator prompt, or from a local-service shell (confirm with whoami /priv).
Account names must be exact. nt authority\local service — a typo like auhority makes PsExec ask for a password and fail ("username or password incorrect"). These are Windows identities, so they only appear in Windows commands.

vi Remediation

Disable the Print Spooler on servers that don't need it. Remove SeImpersonate from service accounts where it isn't required, keep Windows patched, and run services under least-privilege identities.
